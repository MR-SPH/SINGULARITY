## English

### Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

### Reporting a Vulnerability

The SINGULARITY team takes security and software integrity seriously. If you discover a security vulnerability or potential issue within this project:

1. **Do not disclose it publicly** via GitHub issues or discussions.
2. Please send a report via email to `security@example.com` or open a private [GitHub Security Advisory](https://github.com/features/security).
3. Include detailed steps to reproduce the issue, your operating system, and the Python version used.

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for the fix and public release.

### الإبلاغ عن الثغرات الأمنية

يأخذ فريق مشروع **SINGULARITY** أمان البرمجيات وسلامة مستخدميها ببالغ الجدية. إذا اكتشفت ثغرة أمنية أو سلوكاً مشتبهاً به داخل المشروع:

1. **يُرجى عدم نشر الثغرة علناً** عبر تقارير المشاكل (Issues) أو المناقشات العامة (Discussions).
2. يُرجى إرسال تقرير خاص عبر البريد الإلكتروني: `security@example.com` أو فتح إشعار أمني خاص (GitHub Security Advisory).
3. يرجى توضيح خطوات إعادة إنتاج الثغرة، ونظام التشغيل، وإصدار بايثون المستخدم.

سنقوم بتأكيد استلام تقريرك خلال 48 ساعة والعمل على توفير التحديث الأمني في أقرب وقت.
