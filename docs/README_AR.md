## عن المشروع

بدلاً من الاعتماد على المجسمات التقليدية المكسوة بالخامات أو الخطوط الشبكية المجردة، يقوم محرك **SINGULARITY** ببناء المشهد الفلكي للثقب الأسود من آلاف الحروف العربية النشطة. تدور الحروف وتتسارع وتتمدد وفقاً لقوانين النسبية العامة، متحاذية مماسياً مع خطوط الانسياب المداري كخطوط كوزمولوجية مضيئة.

المشروع مصمم ليكون عملاً فنياً سينمائياً وعلمياً راقياً، متفادياً المظهر النمطي البسيط لشاشات الهاكرز الخضراء، ويعمل بسلاسة بمعدل **60 إطاراً في الثانية** حتى على الحواسيب ذات العتاد المتوسط والمعالجات ثنائية النواة بفضل المعمارية الحسابية الموجهة والتخزين المؤقت المكمم.

## الأساس الفيزيائي والرياضي

يعتمد المحرك على معادلات حقيقية مستمدة من الفيزياء الفلكية والنسبية العامة:

### 1. المقياس الفضائي الموحد ($R_s$ Unified Spatial Scale)
تعتمد جميع عناصر المشهد على وحدة طول أساسية موحدة هي **نصف قطر شفارتزشيلد ($R_s$)**:
* **أفق الحدث (Event Horizon):** يقع عند $1.0 \, R_s$ ويمثل الحد المطلق الذي تبتلع فيه المادة.
* **حلقة/كرة الفوتون (Photon Sphere):** تقع عند $1.5 \, R_s$ حيث تنحني مسارات الضوء في مدارات دائرية غير مستقرة.
* **المدار الدائري المستقر الداخلي (ISCO):** يقع عند $3.0 \, R_s$، وتنهار المدارات داخله لتسقط المادة سقوطاً حراً.
* **القرص التراكمي (Accretion Disk):** يمتد من $3.0 \, R_s$ إلى $20.0 \, R_s$.
* **سمك القرص الرأسي:** يتبع النسبة الفيزيائية $H(r) = 0.03 \, r$.

### 2. التدرج الحراري لقرص شاكورا-سونيايف (Shakura-Sunyaev Thin Disk)
يتم حساب درجة حرارة وانبعاث مادة القرص وفق المعادلة الإشعاعية القياسية:
$$T(r) = T_{\text{peak}} \cdot \left(\frac{r}{r_{\text{in}}}\right)^{-3/4} \left[1 - \sqrt{\frac{r_{\text{in}}}{r}}\right]^{1/4}$$
حيث تبلغ الحرارة ذروتها القصوى عند $r \approx 4.08 \, R_s$ متدرجة من الأبيض والذهب الساطع إلى البرتقالي الشمسي ثم الأحمر الداكن.

### 3. الديناميكا المدارية لباتشينسكي-فيتا (Paczyński-Wiita Potential)
لحساب السرعة الزاوية للمدارات النسبية:
$$\Omega(r) = \frac{\sqrt{GM}}{r^{1/2}(r - R_s)}$$
مما يمنح الحروف القريبة من الأفق تسارعاً دورانياً حاداً ومبهراً بصرياً.

### 4. إشعاع دوبلر النسبي (Relativistic Doppler Beaming)
المادة التي تدور مقتربة من الراصد تتضخم شدتها الإشعاعية وفق معامل لورنتز وزاوية خط الرؤية:
$$\delta = \frac{1}{\gamma (1 - \beta \cos\theta)}, \quad I_{\text{obs}} \propto \delta^3$$
مما يمنح الجانب المقترب سطوعاً مضاعفاً بينما يخفت الجانب المبتعد.

### 5. عدسة الجاذبية وانحناء القرص الخلفي (Gravitational Lensing & Halo Arc)
تنحني أضواء النجوم الخلفية والجسيمات الواقعة خلف الثقب الأسود وفق معادلة آينشتاين لانحراف الضوء، مما يرفع صورة القسم الخلفي من القرص المائل لتظهر كقوس ضوئي مقوس أعلى وأسفل ظل الثقب الأسود.

### 6. تموجات موجات الجاذبية (Gravitational Wave Ripples)
عند عبور أي جسيم أفق الحدث، يطلق الثقب الأسود نبضاً حلقياً كوزمولوجياً متوهجاً من موجات الجاذبية يتسع ويتلاشى نحو الخارج في مستوى القرص.

## نظام التيبوغرافيا العربية

* **الأبجدية الـ 28 الأصيلة:** النمط الافتراضي يعتمد على الحروف العربية المفردة كجسيمات بلازما أساسية.
* **التشكيل والسياق العربي (Reshaping & BiDi):** استخدام `arabic-reshaper` و `python-bidi` لضمان اتصال الحروف واتجاه كتابتها الصحيح من اليمين إلى اليسار في الكلمات والجمل.
* **المحاذاة المماسية لخطوط الانسياب:** تدور الحروف تلقائياً لتتطابق مماسياً مع زاوية السرعة المدارية:
  $$\theta_{\text{flow}} = 90^\circ + \arctan2(v_z, v_x)$$
* **أنماط التيبوغرافيا المتعددة:**
  * **الحروف (`letters`):** الأبجدية الـ 28.
  * **الكلمات (`words`):** مصطلحات فلكية مثل: *جاذبية، أفق الحدث، ثقب أسود، تفرد، نور، سرمدي، زمكان*.
  * **الجمل (`phrases`):** اقتباسات فلكية وفلسفية مثل: *في فلك يسبحون، والنجم إذا هوى، انحناء الزمان والمكان*.
  * **المختلط (`mixed`):** مزيج حيوي يجمع بين الحروف والكلمات والعبارات.

## متطلبات التشغيل والبيئة

* **بايثون:** Python 3.11 أو أحدث (متوافق تماماً ومختبر على Python 3.14).
* **نظام التشغيل:** Windows 10/11، Linux (Ubuntu, Debian, Fedora, Arch)، أو macOS.
* **العتاد الأدنى:**
  * معالج: ثنائي النواة بتردد 2.0 GHz أو أعلى.
  * الذاكرة (RAM): 2 جيجابايت.
  * بطاقة الرسوميات: كرت مدمج (Intel HD Graphics أو ما يعادله).

## طريقة التثبيت خطوة بخطوة

### 1. استنساخ المستودع (Clone)
```bash
git clone https://github.com/your-username/singularity.git
cd singularity
```

### 2. إنشاء وتفعيل البيئة الافتراضية
* **على ويندوز (PowerShell):**
  ```powershell
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  ```
* **على لينكس / macOS (Bash):**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

### 3. تثبيت المكتبات المطلوبة
```bash
pip install -r requirements.txt
```

## كيفية التشغيل وخيارات الأوامر

### التشغيل الأساسي
```bash
python main.py
```
أو كحزمة قياسية:
```bash
python -m singularity
```

### خيارات سطر الأوامر (CLI Options)
| الأمر | الوصف | مثال |
| :--- | :--- | :--- |
| `--preset` | اختيار لوحة الألوان | `python main.py --preset deep_blue` |
| `--quality` | جودة الرندرة (`LOW`, `MEDIUM`, `HIGH`) | `python main.py --quality HIGH` |
| `--mode` | نمط التيبوغرافيا (`letters`, `words`, `phrases`, `mixed`) | `python main.py --mode words` |
| `--particles` | تحديد عدد الجسيمات الأولية | `python main.py --particles 1500` |
| `--fullscreen` | فتح المحاكاة بملء الشاشة | `python main.py --fullscreen` |
| `--benchmark` | تشغيل قياس أداء صامت بدون واجهة | `python main.py --benchmark 120` |

## أزرار ولوحة التحكم التفاعلية

| الزر / الاختصار | الوظيفة |
| :--- | :--- |
| **سحب الفأرة (زر أيسر)** | تدوير الكاميرا 360° أفقياً ورأسياً (Pitch & Yaw) |
| **عجلة الفأرة أو `+` / `-`** | تقريب وتصغير المنظور ثلاثي الأبعاد (Zoom In / Out) |
| **`C`** | **تفعيل / إيقاف الوضع السينمائي التلقائي (Cinematic Auto-Tour)** |
| **`Space`** | إيقاف مؤقت / استئناف حركة المحاكاة |
| **`H`** | إظهار / إخفاء لوحة التحكم وشريط الإحصائيات (HUD) |
| **`R`** | إعادة ضبط المشهد والجسيمات |
| **`T`** | التبديل الفوري بين أنماط التيبوغرافيا (حروف &larr; كلمات &larr; جمل) |
| **`Q`** | التبديل بين إعدادات جودة الأداء (LOW &larr; MEDIUM &larr; HIGH) |
| **`1` إلى `5`** | التبديل السريع بين باليتات الألوان (برتقالي، أزرق، بنفسجي، رمادي، زمردي) |
| **`P` أو `F12`** | التقاط لقطة شاشة نقية بدقة فائقة وحفظها في مجلد `screenshots/` |
| **`F11`** | التبديل لملء الشاشة |
| **`Esc`** | الخروج من البرنامج |
