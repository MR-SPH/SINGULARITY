# Contributing to SINGULARITY

Thank you for your interest in contributing to **SINGULARITY: Arabic Gravitational Art Engine**!

## How to Contribute

1. **Fork the Repository**: Create a personal fork on GitHub.
2. **Create a Feature Branch**: `git checkout -b feature/your-feature-name`.
3. **Commit Your Changes**: Follow clear and descriptive commit messages.
4. **Run Tests**: Ensure all automated tests pass before submitting (`pytest`).
5. **Open a Pull Request**: Provide a detailed description of your feature or bugfix.

## Areas for Exploration
- Additional relativistic color presets (e.g., Hawking radiation ultraviolet spectrum).
- Custom Arabic calligraphy font integrations (e.g., Kufic, Ruq'ah, Diwani).
- OpenCL / Compute Shader acceleration for high-end dedicated GPUs.
